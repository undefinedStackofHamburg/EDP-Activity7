LibSys

A web-based Library Management System designed to streamline book cataloging, member management, loan tracking, and fine collection - all in one clean interface.

Key Features
Book Catalog - Add, edit, and track all books with ISBN, author, category, and copy counts
Member Registry - Register and manage library members with status tracking
Loan Management - Issue and return loans with automatic fine calculation (₱5/day)
Fine Tracking - Overdue detection and fine collection reporting
Report Generation - Printable reports for loans, inventory, fines, and members
